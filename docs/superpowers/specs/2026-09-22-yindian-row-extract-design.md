# 音典字表特殊记录提取设计

## 目标

为 `build.py` 增加两个独立的命令行开关：

- `-v, --vocabulary`：从 `data/raw/pull_yindian/` 的音典 TSV 中提取汉字字段包含方框占位符的记录。
- `-n, --note`：从同一批 TSV 中提取解释/注释字段非空的记录。

两个开关可以单独使用，也可以同时使用。它们不参与数据库写入。

## 输出

每个输入地点保持独立文件，不合并地点，也不修改原始拉取目录：

```text
data/raw/extract/
├── vocabulary/
│   └── <地点>.tsv
└── note/
    └── <地点>.tsv
```

输出文件沿用输入文件名和原始 TSV 表头，保留原始行的全部列。没有匹配记录的地点不生成空文件；每次执行会清理对应的提取目录后重新生成，避免保留过期结果。

## 匹配规则

### 方框字表

汉字字段只要包含预定义的方框占位符集合中的任一字符就匹配。集合覆盖常见空白方框、黑方框、勾选框、实心块和替换字符，包括 `□`、`■`、`⬜`、`⬛`、`☐`、`☑`、`☒`、`▯`、`▢`、`▣`、`█`、`�`。

### 注释

解释/注释字段去除首尾空白后仍非空即匹配。字段名兼容音典常见命名：`解釋`、`解释`、`注釋`、`注释`、`notes`。

## 执行时机

- 带 `-m full` 或 `-m diff` 时：先完成音典数据拉取，再执行提取。
- 不带 `-m` 时：直接扫描当前已有的 `data/raw/pull_yindian/`。
- 只有 `-v`、`-n` 或两者时：提取结束后直接退出，不触发默认数据库写入。
- 若同时传入 `-t` 或 `-c`，提取完成后继续执行原有任务。

## 测试

测试覆盖：

1. 多种方框字符都能被提取。
2. 带注释和空注释行的筛选边界。
3. 每个输入地点独立输出，表头与原始列保留。
4. 无匹配地点不生成文件，并在重复执行时清理旧结果。
5. CLI 能解析两个开关，且提取开关不会触发默认写库。
